    Quality

    Your key stays in this browser only (local storage). It is sent to Google and nowhere else.

    Get a key in about 10 minutes
    1. Open Google Cloud and create a project.
    2. Attach a billing account. Google asks for a card even though light use stays within the monthly free allowance.
    3. Enable the Map Tiles API for that project.
    4. In Keys & Credentials, create an API key.
    5. Restrict it. Under Application restrictions pick Websites and add https://laluka.github.io/*. Under API restrictions allow only Map Tiles API.
    6. Optional but wise: in Quotas, cap daily requests, and set a budget alert in Billing.
    7. Paste the key above and press Use key. Fly somewhere with tall buildings and enjoy.

    Usage beyond the free allowance is billed by Google per session. Check the current pricing.
